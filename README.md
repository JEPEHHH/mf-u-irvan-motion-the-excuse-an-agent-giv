# The Excuse an Agent Gives After It Loses

A tiny offline program that writes one deterministic one-line excuse to `entry.txt`.

Run:

  node main.ts

By default the file lands in `/output/entry.txt`. Set `MAKEFUN_OUTPUT_DIR` to write somewhere else. No packages, no network, no API keys.
